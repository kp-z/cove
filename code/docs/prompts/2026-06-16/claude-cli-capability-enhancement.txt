Claude Code CLI 能力优化 Prompt

==================== 目标 ====================

基于调研报告的最佳实践，优化当前项目的 Claude Code CLI 集成，激活其全部能力。

==================== 背景知识 ====================

调研报告揭示的 Claude Code CLI 6 大核心能力：

1. CLI 调用方式
   - --input-format stream-json（NDJSON 双向通信）
   - --output-format stream-json
   - --dangerously-skip-permissions（自动批准工具）

2. Tool 能力
   - 所有内置 Tool 自动可用
   - 通过 --dangerously-skip-permissions 自动批准

3. Skill 能力
   - 自动扫描 .claude/skills/ 目录
   - 无需 CLI 参数

4. MCP 能力
   - 通过 permission_mcp.py 实现权限代理
   - --mcp-config + --permission-prompt-tool

5. 多轮对话
   - asyncio.Queue 消息队列
   - stdin 持续写入，不立即关闭

6. 关键技术
   - NDJSON 协议
   - session_id、tool_call、tool_result 捕获
   - 环境隔离（worktree/Docker/SSH）

==================== 当前实现分析 ====================

主要文件：
  - local/src/infrastructure/adapters/llm/claude-code-cli-adapter.ts

当前已实现：
  - ✅ --output-format stream-json
  - ✅ NDJSON 逐行解析
  - ✅ usage、cost、ttft 捕获
  - ✅ tool_use 事件解析

当前缺失：
  - ❌ --input-format stream-json
  - ❌ --dangerously-skip-permissions
  - ❌ session_id 捕获
  - ❌ tool_result 捕获
  - ❌ 多轮对话支持
  - ❌ MCP 支持
