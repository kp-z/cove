==================== 安全建议 ====================

权限最小化原则：
  - 只给 agent 完成任务必需的 tools
  - 只读 agent（planner、architect）不应该有 Write/Edit
  - 分析类 agent 通常不需要 Bash

危险权限组合：
  - Write + Bash：能创建文件并执行，需谨慎
  - Edit + Bash：能修改代码并运行，高风险
  - 所有权限：仅给完全可信的 agent

建议的权限层级：
  1. 只读层：["Read", "Grep", "Glob"]
  2. 分析层：["Read", "Grep", "Glob", "Bash"]
  3. 文档层：["Read", "Grep", "Glob", "Write"]
  4. 修复层：["Read", "Edit", "Bash", "Grep", "Glob"]
  5. 全能层：["Read", "Write", "Edit", "Bash", "Grep", "Glob", "Agent"]

==================== Agent 工作目录控制 ====================

默认行为：
  - Agent 继承主会话的工作目录
  - 如果主会话在 /Users/kp/项目/Proj/cove/code，agent 也在这里

修改工作目录：
  方法 1：在启动 agent 前 cd 到目标目录
  方法 2：使用 isolation: "worktree" 创建隔离环境
  方法 3：在 agent prompt 中用 Bash 工具 cd（需要 Bash 权限）

Worktree 隔离：
  使用场景：需要在独立分支工作，不影响主分支
  启动方式：Agent tool 的 isolation 参数设为 "worktree"
  效果：在 .claude/worktrees/ 下创建独立工作目录
