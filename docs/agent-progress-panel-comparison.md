## 实时状态流转示意

```
[用户发送消息]
    ↓
┌────────────────────────┐
│ ⏳ 等待接收 · 1s ...   │  ← pending
└────────────────────────┘
    ↓
┌────────────────────────┐
│ ✓ 已接收 · 2s ...      │  ← accepted
└────────────────────────┘
    ↓
┌──────────────────────────────────┐
│ 🧠 思考中 · 5s ...               │  ← thinking
│ ┌──────────────────────────┐    │
│ │ ▶ 思考过程 [可展开]      │    │
│ └──────────────────────────┘    │
└──────────────────────────────────┘
    ↓
┌──────────────────────────────────┐
│ 🔧 工具调用 · 8s ...             │  ← tool_use
│ ┌──────────────────────────┐    │
│ │ 📄 读取文件               │    │
│ │ ▼ 参数 [已展开]          │    │
│ │   file_path: ...         │    │
│ └──────────────────────────┘    │
└──────────────────────────────────┘
    ↓
┌──────────────────────────────────┐
│ 💬 正在回复 · 15s ...            │  ← responding
│                                  │
│ 根据代码分析，这个问题...        │  ← 流式内容
│                                  │
└──────────────────────────────────┘
    ↓
┌──────────────────────────────────┐
│ 根据代码分析，这个问题的根本     │  ← completed
│ 原因是...                        │
│                                  │
│ [完整回复内容]                   │
└──────────────────────────────────┘
```

## 交互改进

### 1. Thinking 内容展开/折叠

**折叠状态**（默认）：
```
┌────────────────────────────────┐
│ ▶ 🧠 思考过程                  │
└────────────────────────────────┘
```

**展开状态**（点击后）：
```
┌────────────────────────────────────────┐
│ ▼ 🧠 思考过程                          │
├────────────────────────────────────────┤
│ 我需要先读取这个文件来理解当前的实现， │
│ 然后分析问题的根本原因。根据用户的描述 │
│ 看起来可能是状态管理的问题...          │
└────────────────────────────────────────┘
```

### 2. Tool 参数展开/折叠

**折叠状态**（默认）：
```
┌────────────────────────┐
│ 📄 读取文件            │
│ ▶ 参数                 │
└────────────────────────┘
```

**展开状态**（点击后）：
```
┌────────────────────────────────┐
│ 📄 读取文件                    │
│ ▼ 参数                         │
│ ┌──────────────────────────┐  │
│ │ file_path: /path/file.ts │  │
│ │ offset: 0                │  │
│ │ limit: 100               │  │
│ └──────────────────────────┘  │
└────────────────────────────────┘
```

## 颜色主题

```
pending/accepted:  🔵 蓝色系  (bg-blue-500/10)
thinking:          🔵 蓝色系  (bg-blue-500/10)
tool_use:          🟣 紫色系  (bg-purple-500/10)
responding:        🟢 绿色系  (bg-green-500/10)
failed:            🔴 红色系  (bg-red-500/10)
```

## 动画效果

- **pending/accepted**: 旋转的加载图标 (animate-spin)
- **thinking**: 脉冲的大脑图标 (animate-pulse)
- **所有阶段**: 跳动的三点省略号 (animate-bounce)
- **等待时间**: 每秒更新的计时器 (tabular-nums)
